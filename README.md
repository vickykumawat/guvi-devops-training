# Advanced Cloud Engineering & DevOps --- Learning Repository

Welcome! 👋

This repository is a shared learning resource for the **Advanced Cloud
Engineering and DevOps** course. It is intended to help students review
class concepts, practise commands, explore examples, complete hands-on
labs, and revise topics after class.

> **How to use this repository:** Start with the relevant module below,
> read the notes, run the practical exercises in your own lab
> environment, and revisit the troubleshooting and revision material
> when needed. Content will be added and improved as the course
> progresses.

## What You Can Find in Each Module

Depending on the topic, a module may contain:

-   **Notes** --- explanations and key concepts covered in class.
-   **Commands and cheat sheets** --- commands for quick reference.
-   **Examples and configuration files** --- scripts, YAML files,
    Dockerfiles, pipeline definitions, and infrastructure code.
-   **Practicals / labs** --- step-by-step exercises to practise the
    topic.
-   **Assignments** --- additional tasks to test your understanding.
-   **Troubleshooting** --- common errors and ways to investigate them.
-   **Interview questions** --- revision questions and scenario-based
    practice.

Not every folder will contain all of these items. Resources will be
added where they make sense for the module.

## Pseudo Sessions and Course Sessions

Introductory or pseudo-session resources will be kept inside the
relevant topic folder rather than in a separate top-level folder. For
example, introductory Git material and later Git practicals will both
live under **Git & Version Control**.

This keeps all resources for a technology together and makes the
repository easier to navigate throughout the course.

## Suggested Learning Workflow

1.  Open the relevant module.
2.  Review the notes before or after class.
3.  Run the commands and examples in your own practice environment.
4.  Complete the practical exercises.
5.  Try the assignments before looking at any provided solution.
6.  Record errors you encounter and use the troubleshooting material to
    investigate them.
7.  Revisit the module's revision questions when preparing for
    interviews.

## Lab Safety and Good Practices

-   Never commit passwords, API tokens, cloud access keys, private keys,
    kubeconfig files, or other secrets.
-   Use a lab or sandbox account for cloud exercises whenever possible.
-   Check potential cloud charges before creating resources, and delete
    lab resources when you finish.
-   Review commands before running them, especially commands that delete
    files or modify infrastructure.
-   Do not upload private student information or material you are not
    permitted to share.

## Keeping the Repository Useful

This repository will evolve as classes progress. Check the relevant
module folder for the latest notes and practicals.

If you find a broken example or an unclear instruction, note the file
name and the issue so it can be corrected.
